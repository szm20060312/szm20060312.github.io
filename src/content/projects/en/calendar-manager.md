## Overview

A personally led object-oriented programming course project at Macau University of Science and Technology. The console application combines a calendar module with algorithm practice.

## Implementation

Calendar events are organized using a doubly linked list, with input handling and file-based persistence. The algorithm module covers memoized Fibonacci calculation, summation functions, templates, and related C++ language features.

## Learning focus

The project connects data representation, memory management, file I/O, and a console interaction flow. It is presented as course work and a record of programming practice.
