## 仓库概述

个人维护的编程和学习练习集合，按照 C、C++、Python、数据结构与 Web 等方向组织资料。

## 用途

本仓库作为学习记录，方便回顾示例和为后续项目积累基础。仓库还将机器学习相关内容列为学习方向，而非已完成的模型训练或科研成果。
