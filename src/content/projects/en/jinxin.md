## Overview

Jin · Xin is a personally led text-based strategy game inspired by Shanxi merchant banking. The player manages a bank through recurring decisions, economic simulation, events, and year-end settlement.

## Implementation

The frontend uses React, TypeScript, and Vite. Game rules and resource changes are organized separately from presentation, with stages for decisions, simulation, events, and settlement. The system connects branch operations, staff development, reputation, and multiple endings.

## My contribution

I led the project, including the design and implementation of the game experience, state transitions, and web interface.

## Scope and resources

This project represents game engineering and rule-based system modelling. The repository also documents cloud-side authentication and persistence work, alongside local build instructions.
